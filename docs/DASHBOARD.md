# Dashboard CMDB

O Dashboard é calculado diretamente a partir do mesmo inventário usado nas demais telas. Nenhum indicador possui uma base separada.

## Filtros globais
País, Location, Device Group, Simple Device Category, Fabricante, Status e Planned Replacement Year.

## Indicadores
Total filtrado, ativos, outros status, obsoletos, NeedsReview, duplicados, replacement do ano atual e Replacement Cost.

## Análises
- Equipamentos por Location
- Status operacional
- Simple Device Category
- Device Group
- País/Região
- Fabricante
- Planned Replacement Year com quantidade e custo
- Obsolescência
- Qualidade dos dados
- Últimas movimentações

Ao importar uma nova planilha, os gráficos são recalculados automaticamente a partir do InventarioContext.
